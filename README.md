# orphera.github.io

[Orphera](https://github.com/orphera) 팀의 공식 포털 및 프로젝트 소개 웹사이트입니다.

🌐 **웹사이트**: [https://orphera.github.io/](https://orphera.github.io/)

---

## 📂 사이트 구조

- **`/` (루트)**: Orphera 팀 소개 및 전체 프로젝트 허브 (Overmax, ShadowMAX)
- **`/overmax/`**: [Overmax](https://github.com/orphera/overmax) 전용 소개 및 릴리즈 다운로드 페이지

---

## 🛠️ 로컬 미리보기

```bash
# 루트 디렉토리에서 간단한 로컬 웹 서버 실행
python -m http.server 8080
```

- 메인 페이지: `http://localhost:8080/`
- Overmax 페이지: `http://localhost:8080/overmax/`

---

## 📸 Overmax 스크린샷 추가

`overmax/assets/images/` 폴더에 `hero-preview.gif` (또는 `hero-preview.png`)를 추가하면 `/overmax` 페이지의 플레이스홀더가 실제 이미지로 자동 교체됩니다.
