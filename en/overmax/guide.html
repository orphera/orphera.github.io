01 Installation & Quick Start

Overmax is provided as a standalone portable package requiring no heavy installers.

STEP 01

Download Package

Download the latest overmax.zip from the download section.

STEP 02

Extract & Run

Extract the files to any folder and execute overmax.exe.

STEP 03

Automatic Detection

Launch DJMAX RESPECT V. Overmax detects the game window and automatically displays the overlay.

💡 Smart Auto Update
When launched, Overmax checks for the latest song database (image_index.db) and app updates in the background to ensure metadata is always current.

02 ⚠️ Game Display Settings (Must-Read)

Due to the anti-cheat system (XIGNCODE3) and Windows window rendering rules, please verify your in-game display mode setting below.

✅ Recommended: Borderless Fullscreen (Borderless Window)
Set the in-game display mode in [OPTION] → [GRAPHICS] → Display Mode to "Borderless". This ensures the overlay sits properly on top of the game without being blocked.
🖥️ If You Must Use Exclusive Fullscreen

If the game is launched in traditional "Fullscreen" mode, Windows OS will hide overlays behind the game screen.
If your setup strictly requires Exclusive Fullscreen, you can drag the Overmax window to a secondary monitor in a dual-display setup.

03 Overlay HUD Overview

1) Top Header & Quick Actions

  • Song Info & Accuracy: Displays the currently selected song title, artist, button mode (4B/5B/6B/8B), real-time personal best Rate, and MAX COMBO ([M], [P]) badges.
  • ⬆ One-Click Upload: Activates when a new score higher than your existing V-Archive record is detected. Click to upload immediately to the server.
  • 🔄 Sync Window: Opens a dedicated window to inspect multiple locally accumulated scores and upload or clean them up in batches.
  • ⚙ Settings: Opens the configuration window to adjust scale, opacity, recommendation mode, and V-Archive account binding.

2) Unofficial Difficulty Tier List

Displays detailed unofficial difficulty ratings (e.g. 10.1) for each difficulty chart (NM / HD / MX / SC) powered by V-Archive data. The currently selected pattern is highlighted.

3) Personalized Song Recommendations

Analyzes your personal rating distribution and current session performance to recommend the most suitable songs for rating progression.

🏷️ Recommendation Reason Badges
  • TOP
    Top-50 Breakthrough: Strong candidate song capable of entering your V-Archive Top 50 rating cutline (maximizes rating increase).
  • DEF
    Top-50 Defense: A song currently ranked 41st–50th on your profile at risk of falling out of the Top 50.
  • UP
    Upward Momentum: Your session Performance Rating is hot today; higher-tier challenge songs worth tackling now.
  • REST
    Recovery / Warm-Up: Consistent comfort songs for finger warming or regaining consistency during low condition.
  • TRY
    Retry Candidate: Close to target accuracy but narrowly missed, and unplayed in the last 14 days. High probability for rating renewal.
  • CLR
    Unplayed First Clear: Newly encountered pattern that has no record registered yet.

💡 In the in-game overlay, hovering over any badge reveals a detailed tooltip explaining why the song was selected.

4) Bottom Footer & Recommended Difficulty Label

Anchors your optimal target difficulty and statistics in the footer regardless of cursor position on the song select screen.

🎯 Rec. SC 13
Avg 99.12% (14/20)
  • Recommended Difficulty (Left): Optimal difficulty derived from a TrueSkill-based statistical skill model (SkillProfile).
  • Band Average Accuracy (Right): Aggregates your average accuracy rate and completion ratio within that recommended tier.

04 Settings & Customization (⚙)

Clicking the gear icon (⚙) in the overlay header opens a settings dialog with 4 dedicated tabs.

⚙️ [General] Tab
  • Scale (S / M / L / XL): 4 scaling tiers optimized for various resolutions (FHD, QHD, 4K).
  • Opacity Slider: Adjust background transparency so it doesn't obstruct in-game sightlines.
  • Corner Snap: Snap cleanly to any of the 4 corners (↖ Top-Left, ↗ Top-Right, ↙ Bottom-Left, ↘ Bottom-Right) or freely drag anywhere.
  • Language (i18n): Supports English, Korean, and Japanese.
🎯 [Recommendation] Tab
  • Mode: Choose between multidimensional Smart mode and simple rate-sorted Classic mode.
  • Target Rate: Set your target accuracy baseline (97%, 99% (Default), 99.5%, or 100%).
  • Exclude Unowned DLC: Automatically infers your owned DLCs from play history to prevent recommending unowned songs.
☁️ [V-Archive] Tab
  • V-Archive ID: Enter your nickname to sync your profile records automatically.
  • account.txt Path: Specify your V-Archive client credentials file to enable live score uploads.
🔧 [Advanced] Tab
  • Capture Backend: Switch between default automatic mode, GDI, and high-speed DXGI Desktop Duplication at runtime.
  • DisplayAffinity (Exclude from Capture): Toggle whether the overlay is invisible in screenshots and streaming software (OBS).
🪶 Lite Mode Overview
An ultra-slim ~60px height bar layout that hides extra lists and displays only vital real-time info.
Both standard HUD and Lite Mode support 4-corner snapping and smooth mouse dragging.

05 V-Archive Sync & Sync Window Guide

Overmax requires no complex API tokens. Depending on your needs, you can use it for Score Lookup Only or Live & Batch Score Uploads.

📥 Case 1: Looking Up Scores & Tiers Only (Read-Only)

Displays your existing V-Archive records and unofficial difficulties on the overlay for in-game reference.

  1. Click the Settings icon (⚙) in the overlay header and navigate to the [V-Archive] tab.
  2. Enter your V-Archive ID (nickname).
  3. Click [Refresh] to fetch your records immediately.
  4. Overmax will automatically retrieve the latest records whenever the app starts.

📤 Case 2: Uploading High Scores to V-Archive

Allows submitting new records achieved during play directly to V-Archive.

  1. Enter your V-Archive ID (nickname) in the Settings dialog (⚙).
  2. Specify the path to your account.txt authentication file used by the official V-Archive client.

🔄 Detailed Guide: V-Archive Sync Window

Click the 🔄 Sync button on the right side of the header to open this window. Review records accumulated in your local database (record.db), upload selected records, or delete unwanted entries.

🔍 1. Account Check & Scan

Automatically detects the active Steam account (nickname & Steam ID) on your PC.

  • [Scan] Button: Compares locally collected records against V-Archive data to find unregistered songs and improvement candidates.
  • Supports manual Steam ID switching for multi-account systems.
🎛️ 2. Smart Filters (▼)

Click the ▼ Filter button to narrow down candidate patterns quickly.

  • Button Mode & Difficulty: Independent toggles for 4B/5B/6B/8B and NM/HD/MX/SC
  • Level & Rate Dual Sliders: Filter by Lv.1 ~ SC 15 and 0% ~ 100%
  • Special Conditions: "Show only V-Archive missing MAX COMBO", "Exclude unregistered", etc.
📊 3. Candidate Sorting

Sort discovered candidates (e.g. 12 / 45) according to your preferences.

  • Rate Diff: Sorts by accuracy improvement margin (e.g. +0.45%), placing high-impact rating boosters first.
  • Title: Sorts alphabetically by button mode and song title.
⚡ 4. Upload & Local Deletion

Inspect each candidate's Rate, MAX COMBO status, and reason badge before taking action.

  • [Upload]: Transmits the pattern record to V-Archive with immediate success/error status.
  • [Delete]: Safely deletes misrecognized or unwanted records from the local database.
💡 Real-time Upload (⬆) vs Sync Window (🔄) Comparison
  • Header ⬆ Button (Real-time): Best for uploading a single pattern immediately after setting a new personal best during play. (Includes a 3-second toast feedback)
  • Header 🔄 Button (Sync Window): Best after completing a full session to review multiple accumulated records in bulk, filter selectively, or clean up local logs.

06 Frequently Asked Questions (FAQ)

Q. Screen recognition is not working at all.
Make sure DJMAX RESPECT V is running and that the display mode is set to "Borderless" or "Windowed". Also verify that Overmax has standard user permissions and is not being blocked by conflicting graphics overlay software.
Q. The overlay doesn't appear or recognize songs on a dual/multi-monitor setup.
Depending on virtual coordinate layouts in multi-monitor setups, DXGI capture may miss secondary screens.
Open Settings (⚙) → [Advanced] Tab and change the Capture Backend to "GDI" for universal compatibility across any display configuration.
Q. The overlay does not show up in screenshots or stream recording tools (OBS, etc.).
To prevent the overlay window from recognizing its own visuals during screen capture, Windows DisplayAffinity (capture exclusion) is enabled by default.
To include the overlay in streams or recordings, go to Settings (⚙) → [Advanced] Tab → uncheck [Exclude from Screen Capture].
⚠️ Caution: When capture exclusion is disabled, ensure the overlay is moved away from the game UI recognition zones (e.g. to a secondary monitor or bottom corner) to avoid self-interference.
Q. Is there any risk of bans for memory modification or DLL injection?
No. Overmax does not hook into, inject, or read the game process memory. It operates strictly by capturing window frames via standard Win32 APIs, ensuring complete safety.
Q. Is Linux supported?
Yes. A dedicated package for x86_64 Linux (Proton / XWayland) is provided (overmax-linux-x86_64.tar.gz). Please refer to the Linux guide on GitHub for detailed setup steps.
