Key Features

🎯

Personalized Recommendations

Analyzes Top-50 breakthrough candidates, narrow-miss retries, and today's session condition to recommend optimal songs for rating growth with clear reason badges.

⬆️

Real-time Record & Quick Upload

Detects live accuracy rate during play and lights up the upload button (⬆) in the header whenever you achieve a new high score, enabling one-click upload to V-Archive.

🪶

Lite Mode

Provides an ultra-compact ~60px slim bar layout that securely snaps to any of the 4 screen corners without shaking, keeping you fully immersed in the gameplay.

Quick Start

View Full Guide →
STEP 01

Extract Package

Download the latest overmax.zip and extract it to your preferred folder.

STEP 02

Run Application

Launch overmax.exe. It automatically checks and updates the latest song database.

STEP 03

Launch Game

Start DJMAX RESPECT V. Overmax detects the game window and overlays seamlessly.

💡 Display Setting Required: Set in-game display mode to "Borderless Window" (Borderless Fullscreen). Learn more
