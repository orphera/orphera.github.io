Overmax 사용 가이드

Overmax의 설치부터 게임 화면 설정, 주요 기능 및 V-Archive 연동까지 상세한 사용법을 안내합니다.

1. 설치 및 빠른 시작

Overmax는 별도의 무거운 인스톨러 없이 바로 실행 가능한 포터블(Portable) 단일 패키지로 제공됩니다.

  1. 다운로드 페이지에서 최신 overmax.zip을 다운로드합니다.
  2. 원하는 폴더에 압축을 풉니다.
  3. overmax.exe를 실행합니다.
  4. DJMAX RESPECT V를 실행하면 자동으로 게임 창을 인식하여 오버레이가 뜹니다.

💡 자동 업데이트: 앱 실행 시 자동으로 최신 곡 DB(image_index.db) 및 최신 버전 여부를 확인하여 백그라운드에서 동기화합니다.

2. ⚠️ 게임 화면 설정 (필독)

게임 안티치트(XIGNCODE3) 및 Windows OS의 렌더링 제약으로 인해 아래 설정을 반드시 확인해 주세요.

권장 설정: 전체 창 모드 (Borderless Fullscreen)
게임 내 [OPTION] → [GRAPHICS] → 화면 모드를 "전체 창 모드"로 설정해 주세요. 게임 화면 위에 오버레이가 가려지지 않고 정상적으로 오버랩됩니다.

독점 전체화면을 사용해야 하는 경우

게임을 일반 "전체화면(Fullscreen)"으로 실행하면 오버레이가 게임 창 뒤로 숨겨지게 됩니다. 독점 전체화면을 반드시 사용하셔야 하는 환경이라면 오버레이 창을 드래그하여 듀얼 모니터의 보조 화면에 두고 플레이하시면 됩니다.

3. 오버레이 화면 보는 법

1) 상단 헤더 및 퀵 액션

  • 곡 정보 및 판정: 현재 선택된 곡명, 아티스트, 버튼 모드(4B/5B/6B/8B), 실시간 최고 달성률(Rate) 및 MAX COMBO([M], [P]) 뱃지를 표시합니다.
  • ⬆ 원클릭 업로드: 기존 V-Archive 기록보다 높은 신기록이 감지되면 활성화되며, 누르면 즉시 웹서버로 단독 업로드됩니다.
  • 🔄 기록 동기화 (Sync): 로컬에 누적된 여러 신기록을 한눈에 검토하고 일괄 업로드/삭제할 수 있는 동기화 창을 엽니다.
  • ⚙ 설정: 크기, 투명도, 스마트 추천 모드, V-Archive 계정 연동 등을 조절하는 설정 창을 엽니다.

2) 비공식 난이도 티어표

V-Archive 데이터를 바탕으로 각 난이도(NM / HD / MX / SC)의 세분화된 비공식 난이도 수치(예: 14.2, 14.8)를 보여줍니다. 현재 선택된 패턴은 시각적으로 강조 표시됩니다.

3) 지능형 다차원 스마트 추천 리스트 (v0.4.0)

단순 오름차순 정렬을 넘어, 플레이어의 실력 분포와 당일 컨디션을 통계적으로 분석하여 실력 향상과 기록 갱신에 가장 효과적인 곡을 똑똑하게 선별합니다.

🏷️ 추천 사유 뱃지 안내
  • TOP
    Top-50 돌파: V-Archive Top 50 랭킹 컷라인 돌파가 가능한 유력 후보곡 (레이팅 상승 극대화)
  • DEF
    Top-50 수성: 현재 내 41~50위에 위치하여 밀려날 위기에 있는 방어 대상 곡
  • UP
    상승 모멘텀: 오늘 세션의 컨디션(Performance Rating)이 좋아 도전해 볼 만한 상위 난이도 곡
  • REST
    회복/안정화: 컨디션이 저조하거나 손풀기가 필요할 때 감각 유지를 위한 안정권 곡
  • TRY
    재도전: 목표 정확도에 근접했으나 아쉽게 놓치고 최근 14일간 플레이하지 않아 방치된 기록 갱신 유력 곡
  • CLR
    미플레이 첫 클리어: 아직 한 번도 기록이 등록되지 않은 신규 패턴

💡 인게임 오버레이에서 각 뱃지에 마우스를 올리면 상세한 추천 이유(호버 툴팁)를 확인할 수 있습니다.

4) 하단 푸터 & 권장 난이도 라벨

  • 🎯 권장 난이도 (예: 🎯 권장 SC 13): TrueSkill 기반 통계적 실력 분포 모델(SkillProfile)을 통해, 선곡창 커서 위치와 무관하게 플레이어의 현재 실력대에 맞는 안정적인 권장 레벨을 일관되게 고정 표시합니다.
  • 대역 평균 달성률 (예: 평균 99.12% (14/20)): 해당 권장 난이도 대역 내에서 플레이어가 달성한 평균 Rate 및 완주 곡 비율을 실시간으로 집계해 보여줍니다.

4. 설정 및 커스터마이징 (⚙)

오버레이 헤더의 톱니바퀴 버튼(⚙)을 누르면 4개 전용 탭으로 구성된 설정 창이 열립니다.

[일반 탭]

  • 크기 조절 (S / M / L / XL): 모니터 해상도(FHD, QHD, 4K 등)에 맞춰 4단계 스케일로 조절할 수 있습니다.
  • 투명도 조절: 정밀 슬라이더를 통해 인게임 시야에 방해되지 않도록 배경 투명도를 조절합니다.
  • 다국어 지원 (i18n): 한국어, English, 日本語 3개 국어를 지원합니다.
  • 라이트 모드 (Lite Mode): 부가 요소를 숨기고 약 60px 초슬림 바로 전환하며, 화면 4개 구석으로 흔들림 없이(Jitter-free) 자동 스냅 고정됩니다.

[추천 탭]

  • 추천 모드: 다차원 분석 기반 스마트(Smart) 모드와 단순 달성률 정렬 클래식(Classic) 모드 중 선택할 수 있습니다.
  • 목표 정확도 (Target Rate): 97%, 99%(기본), 99.5%, 100% 중 본인의 플레이 지향점(클리어 순회 vs 판정 퍼펙트)에 맞춰 권장 난이도 기준을 설정할 수 있습니다.
  • 미보유 DLC 제외: 플레이 기록을 바탕으로 보유한 DLC를 자동 추론하여 미보유 곡 추천을 방지합니다.

[V-Archive 탭 & 고급 탭]

  • V-Archive 연동: 닉네임 조회 연동 및 account.txt 파일 경로 설정을 직관적으로 분리 관리합니다.
  • 캡처 백엔드 (고급): 기본 자동 모드 외에 GDI 및 고속 DXGI Desktop Duplication을 런타임에 직접 선택할 수 있습니다.

5. V-Archive 연동 & 신기록 업로드

Overmax는 복잡한 API 토큰 없이, 사용 목적에 따라 아래 두 가지 방식으로 간편하게 연동하여 사용할 수 있습니다.

경우 1. 내 플레이 기록만 불러오고 싶은 경우 (조회 전용)

V-Archive에 등록된 본인의 플레이 기록과 비공식 난이도를 오버레이에 띄워두고 참고하며 플레이하는 방법입니다.

  1. 오버레이 헤더의 설정 버튼(⚙)을 누르고 [V-Archive] 탭으로 이동합니다.
  2. 본인의 V-Archive ID(닉네임)를 입력합니다.
  3. [새로고침] 버튼을 누르면 V-Archive의 플레이 기록을 즉시 가져옵니다.
  4. 이후에는 Overmax가 실행될 때마다 자동으로 최신 V-Archive 기록을 가져와 오버레이에 반영합니다.

경우 2. 플레이 중 신기록을 V-Archive에 업로드하고 싶은 경우

게임 내에서 실시간으로 갱신한 신기록을 원클릭으로 V-Archive에 직접 등록하는 방법입니다.

  1. 설정 창(⚙)에서 본인의 V-Archive ID(닉네임)를 입력하여 연동합니다.
  2. V-Archive 클라이언트 프로그램에서 사용되는 account.txt 파일 경로를 설정 창에 지정해 줍니다.

💡 업로드 방법 (2가지 지원):

  • 원클릭 실시간 업로드: 플레이 중 기존 V-Archive 기록을 갱신하면 오버레이 우측 상단에 ⬆ 업로드 버튼이 활성화됩니다. 이 버튼을 누르면 방금 플레이한 기록이 즉시 업로드됩니다.
  • V-Archive 동기화 창 이용: 별도의 동기화 창을 열어 오버레이가 수집해 둔 여러 기록들을 검토하고 한 번에 업로드할 수 있습니다.

6. 자주 묻는 질문 (FAQ)

Q. 화면 인식이 전혀 동작하지 않아요.
DJMAX RESPECT V가 정상 실행 중인지 확인하고, 게임 화면 설정이 "전체 창 모드" 또는 "창 모드"인지 확인해 주세요. 관리자 권한 문제나 특수 그래픽 오버레이 도구와의 충돌 여부도 점검해 보세요.
Q. 듀얼/멀티 모니터 환경에서 오버레이가 정상적으로 뜨지 않거나 인식이 안 돼요.
다중 모니터 배치나 디스플레이 가상 좌표 환경에 따라 DXGI 캡처 백엔드가 보조 화면을 놓칠 수 있습니다.
오버레이 헤더의 설정 버튼(⚙) → [고급] 탭으로 이동한 뒤, 캡처 백엔드를 "GDI"로 변경해 주시면 모든 모니터 환경에서 가장 안정적으로 동작합니다.
Q. 메모리 변조나 인젝션으로 인한 제재 위험은 없나요?
Overmax는 게임 프로세스의 메모리를 읽거나 변조하지 않으며, 오직 Win32 창 캡처 API만을 사용하여 화면 이미지를 인식하므로 안전합니다.
Q. Linux에서도 사용할 수 있나요?
네, x86_64 Linux 환경(Proton / XWayland)을 위한 배포 패키지(overmax-linux-x86_64.tar.gz)를 제공합니다. 자세한 실행 가이드는 GitHub의 Linux 가이드 문서를 참고해 주세요.
